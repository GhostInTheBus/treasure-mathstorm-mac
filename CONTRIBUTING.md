# Contributing

Issues and pull requests are welcome.

* Open an issue first for anything bigger than a typo, so we can agree on the approach.
* Never attach or commit game files, disc images or extracted game data. Describe the problem instead.
* Bugs in the emulator belong upstream at [Infinite Mac](https://github.com/mihaip/infinite-mac/issues). Bugs in these notes or the setup steps belong here.
