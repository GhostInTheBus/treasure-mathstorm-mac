# ELI5

Treasure MathStorm is a maths game from the 1990s. Your computer today cannot run it directly.

Instead of running the game on your computer, we run a pretend old Mac inside a web page. The pretend Mac thinks it is 1996 and has a CD drive. We hand it a copy of the game's CD, and the game starts like it did back then.

The web page and the pretend Mac are made by other people. We did not copy the game into this repo, because it belongs to its makers. You bring the disc. These notes just tell you which buttons to press.
